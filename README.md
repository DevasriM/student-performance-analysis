# Student Performance Analysis

A Python-based exploratory data analysis project that investigates student grades and their relationships with study time, previous failures, and absences.

## Objectives
- Analyze overall student academic performance.
- Compare grades across study-time categories.
- Investigate the relationship between previous failures and final grades.
- Explore correlations among selected academic variables.
- Practice data cleaning, statistical analysis, and data interpretation.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib and Seaborn
- Google Colab

## Dataset
The dataset contains 395 student records and 33 attributes.

Source: [UCI Student Performance Dataset](https://archive.ics.uci.edu/dataset/320/student+performance)

## Key Results
- Average final grade: 10.42/20
- Median final grade: 11/20
- Students scoring at least 10/20: 265 (67.09%)
- Correlation between absences and final grade: approximately 0.034
- Students with more previous failures had lower average final grades in this dataset.

These are descriptive findings and do not establish causal relationships.

## Project Files
- `student-performance-analysis.ipynb` — analysis notebook
- `images/` — selected screenshots of the analysis outputs

## How to Run
1. Open the notebook in Google Colab.
2. Upload the required dataset when prompted.
3. Run the notebook from top to bottom.

## Limitations
The findings describe the supplied dataset and may not generalize to other student populations. Correlation does not imply causation.
